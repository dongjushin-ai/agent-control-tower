# Changelog

## 0.1.0 (unreleased)

First public version.

- CLI: `init`, `log` (validation, secret refusal, `--push` with rebase and retry), `run`, `status` (text, JSON, Markdown; exit code 2), `build`, `serve`
- Static dashboard: state cards, 7-day strip in a configurable time zone, success rate and coverage, silent-task alerts, dark mode, English and Korean, built-in demo data
- GitHub Actions templates: hourly watchdog (works in private repos) and Pages deploy
- Snippets for Claude Code, other LLM agents, cron/systemd and GitHub Actions
